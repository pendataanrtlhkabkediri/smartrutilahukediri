01 · Informasi Penting

Pemutakhiran Data RTLH Tahun 2027

Dalam rangka persiapan Program Bedah Rumah / BSPS Tahun 2027 ke Kementerian Perumahan dan Kawasan Permukiman, perlu dilakukan pemutakhiran data Rumah Tidak Layak Huni (RTLH) di SMART RUTILAHU.

Berikut kami sampaikan format permintaan data export RTLH Desa dan format permohonan penghapusan data RTLH di SMART RUTILAHU, serta formulir permohonan reset MFA.
